# Midea AC

Instaladores do **Midea AC**, app de bandeja (Windows) e de barra de menus (Mac) para controlar ar-condicionado Midea pela rede local.

Baixe a versão mais recente em **[Releases](https://github.com/lucasyn3/midea-ac-releases/releases/latest)**:

| Sistema | Arquivo |
|---|---|
| Windows | `MideaACSetup.exe` |
| Mac com chip Apple (M1 ou mais novo) | `MideaAC-apple-silicon.dmg` |
| Mac com processador Intel | `MideaAC-intel.dmg` |

Depois de instalado, o próprio app avisa quando sai uma versão nova: é só clicar em **Atualizar** no painel.
